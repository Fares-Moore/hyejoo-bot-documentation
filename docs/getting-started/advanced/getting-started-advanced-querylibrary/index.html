Optional Command Parameter Library 🧩

This page is a deep reference for players who want precise control over commands. The bot supports several parameter styles across card, claim, collection, and effect commands — and once you learn the patterns, you can slice, sort, and filter your way to exactly the cards you're looking for.

note

Not every command uses every parameter. Many of these options show up most often in card-related flows like /cards, /claim cards, /summon, /eval, and collection commands.

Card Query (card_query) — the heart of card commands​

The card_query parameter is the single most powerful tool in the bot. You feed it a string of keywords, filters, and sorters, and the bot parses them all at once. You can combine as many as you want in a single query.

Basic keyword search — just type a name or partial name:

CommandWhat it does
/cards card_query:twiceSearch cards by collection/name
/cards card_query:moPartial name matches work too
/summon card_query:chaeyoungSummon a specific card by name

The bot matches card names using regex, so partial matches work fine. You don't need to type the full name.

tip

If you want to search for a card by its ID rather than name, the bot also auto-completes IDs in Discord's parameter dropdown!

Filtering syntax (- and !)​

This is the core of advanced queries. Prefix a filter with - to include or ! to exclude. The parser treats every space-separated word that starts with - or ! as a filter.

By collection​

CommandWhat it does
/cards card_query:-twiceShow only cards from the twice collection
/cards card_query:-iveShow only cards from the ive collection
/cards card_query:!blackpinkExclude all blackpink cards
  • -collection — show only cards from that collection
  • !collection — exclude all cards from that collection

The bot auto-matches collection names, so you can use partial names. For example -twice matches the twice collection.

By star level (rarity)​

CommandWhat it does
/cards card_query:-3Show only 3★ cards
/cards card_query:-1 -2Show only 1★ and 2★ cards
/cards card_query:!4Exclude all 4★ cards
/cards card_query:!1 !2Exclude 1★ and 2★ cards
  • -1, -2, -3, -4, -5 — show only cards of that star level
  • !1, !2, !3, !4 — exclude cards of that star level

These are numeric filters on the card's level (star rating), not the card's name.

By card type / promo status​

CommandWhat it does
/cards card_query:-promoShow only promo-type cards
/cards card_query:!promoExclude promo cards (show only normal)
/cards card_query:-limitedShow only limited cards
/cards card_query:!liveauctionExclude live auction cards
/cards card_query:-lotteryShow only lottery cards
/cards card_query:!lotteryExclude lottery cards

The bot checks if the card's collection is promo/limited/liveauction/lottery/etc. and filters accordingly.

By card state (inventory only)​

These filters only work when querying your own card inventory (not global):

CommandWhat it does
/cards card_query:-favOnly favorited cards
/cards card_query:!favOnly non-favorited cards
/cards card_query:-lockOnly locked cards
/cards card_query:!lockOnly unlocked cards
/cards card_query:-newCards obtained since your last /daily
/cards card_query:!newCards obtained before your last /daily
/cards card_query:-ratedCards you have rated
/cards card_query:!ratedCards you haven't rated
/cards card_query:-wishCards on your wishlist
/cards card_query:!wishCards not on your wishlist
/cards card_query:-multiCards you own more than 1 of
/cards card_query:!multiCards you own exactly 1 of

By animation​

CommandWhat it does
/cards card_query:-gifAnimated cards only
/cards card_query:!gifStatic (non-animated) cards only

By group type​

CommandWhat it does
/cards card_query:-girlgroupsGirls groups only
/cards card_query:-boygroupsBoy groups only
note

Soloists are usually treated by their assigned gender group rather than having their own category.

With fragments​

CommandWhat it does
/cards card_query:-fragmentsOnly fragment collection cards

Recipe cards​

CommandWhat it does
/cards card_query:-recipeCards assigned to an active recipe in your inventory
/cards card_query:!recipeExclude recipe-assigned cards

Sorting with > and <​

You can sort the results by prepending > (descending) or < (ascending) to a sort key.

CommandSort direction
/cards card_query:>nameAlphabetical A→Z
/cards card_query:<nameReverse alphabetical Z→A
/cards card_query:>starHighest star level first
/cards card_query:<starLowest star level first
/cards card_query:>evalMost valuable (Flakes Cost) first
/cards card_query:<evalLeast valuable (Flakes Cost) first
/cards card_query:>dateNewest first (by obtained date)
/cards card_query:<dateOldest first
/cards card_query:>ratingHighest rated first
/cards card_query:<ratingLowest rated first
/cards card_query:>levelsHighest XP/level first
/cards card_query:<levelsLowest XP/level first
/cards card_query:>colAlphabetical by collection name
/cards card_query:<colReverse alphabetical by collection name
/cards card_query:>amountMost copies first
/cards card_query:<amountFewest copies first

If no sort is given, the default order is star level descending → collection → name.

tip

You can chain sorts! For example, >col <star sorts by collection A→Z, then by star level ascending within each collection.

Amount filters​

CommandWhat it does
/cards card_query:>2Cards where you own more than 2 copies
/cards card_query:<5Cards where you own fewer than 5 copies
/cards card_query:=1Cards you own exactly 1 copy of
/cards card_query:>=3Cards where you own 3 or more copies

These are numeric comparisons on the amount property. Works in your personal inventory only.

Special symbols​

. — last viewed card​

CommandWhat it does
/summon card_query:.Summon the last card you viewed
/info card_query:.Show info on the last card you viewed

The dot . references the last card you viewed or interacted with. The bot stores this per-user, so you can quickly pull up the same card again without re-typing the name.

#tag — filter by user-created tags​

CommandWhat it does
/cards card_query:#cuteShow cards tagged with cute
/cards card_query:#rare !#commonShow cards tagged rare but not common

Tags are user-submitted labels on cards (managed via /tag commands). You can filter for cards that have (or don't have) specific tags.

  • #tag — show cards with this tag
  • !#tag — exclude cards with this tag

:extra — command-specific extra data​

CommandWhat it does
/effect use effect_name:judgeday extra_arguments:claimrecallUse Judgment Day to copy Claim Recall
/effect use effect_name:spaceunity extra_arguments:-iveUse Space Unity to target the ive collection

The colon : prefix passes extra arguments that some commands interpret differently. For instance, with The Judgment Day effect, everything after the effect name in extra_arguments is forwarded to the copied effect.

$source — filter by image source​

CommandWhat it does
/cards card_query:$booruShow cards with image sourced from booru

Filters cards whose metadata has a matching source tag. This is a niche filter used alongside /meta commands for source tracking.

Command-specific optional parameters​

Beyond the card query syntax, many commands have their own dedicated optional parameters. Here's the full list grouped by command.

/claim cards and /level claim​

ParameterTypeWhat it does
countNumberHow many cards to claim at once (e.g., count:5)
promoBooleanClaim using promo currency instead of flakes
anyBooleanSkip the autocomplete step and claim any random card
boost_idStringTarget a specific active event/boost (e.g., boost_id:christmas25)
group_typeStringRestrict to a group category (e.g., girlsgroups, boygroups)
unlockedBooleanOnly claim from unlocked collections

/cards​

ParameterTypeWhat it does
card_queryStringYour inventory cards matching this query
globalBooleanIf true, search the global card pool instead of your inventory

/sell​

ParameterTypeWhat it does
card_queryStringCard(s) to sell
priceNumberOptional — set a custom price for /sell one
countNumberOptional — how many to sell for /sell many

/eval​

ParameterTypeWhat it does
card_queryStringCard(s) to evaluate
countNumberHow many cards to eval at once
globalBooleanEvaluate from the global card pool instead of your inventory

/fav, /rate, /wish, /lock​

ParameterTypeWhat it does
card_queryStringCard(s) to target
countNumberHow many cards to process at once
(subcommand)Stringone, many, remove one, remove many, or list

/forge, /ascend, /combine​

ParameterTypeWhat it does
card_query_1StringFirst card to use
card_query_2StringSecond card to use

Both queries use the full card query syntax, so you can use filters, sorts, and keywords for each slot.

/liquefy​

ParameterTypeWhat it does
card_queryStringCard(s) to liquefy
countNumberHow many cards to liquefy at once

/draw​

ParameterTypeWhat it does
card_queryStringWhich card or card type to draw towards

/hero equip​

ParameterTypeWhat it does
slot_numberNumberWhich effect slot to equip into (1, 2, 3, etc.)
effect_nameStringThe effect ID to equip (e.g., tohrugift, cherrybloss)

/effect use​

ParameterTypeWhat it does
effect_nameStringThe effect to activate (e.g., claimrecall, judgeday)
extra_argumentsStringExtra data passed to the effect (required for judgeday and spaceunity)

/effect info, /hero info​

ParameterTypeWhat it does
effect_name / heroStringWhich effect or hero to look up

/hero get​

ParameterTypeWhat it does
heroStringHero name or ID to set as your active hero

/hero list​

ParameterTypeWhat it does
heroStringOptional — filter the hero list by name

/profile​

ParameterTypeWhat it does
user_idStringOptional — view another user's profile instead of your own

/diff for / /diff from​

ParameterTypeWhat it does
user_idStringRequired — the other user to compare against
card_queryStringOptional — filter the comparison to specific cards

/has​

ParameterTypeWhat it does
user_idStringRequired — the user to check
card_queryStringRequired — which card to check for

/achievements​

ParameterTypeWhat it does
missingBooleanIf true, show only achievements you haven't completed yet

/collection​

ParameterTypeWhat it does
collectionStringCollection name or ID for /collection info, /collection reset
(filters)Various/collection list supports card-query-style filters

/auction​

ParameterTypeWhat it does
card_queryStringFilter auctions by card (for /auction list, /auction preview)
auction_idStringTarget a specific auction (for /auction info, /auction bid, /auction cancel)
meBooleanShow only your own auctions
bidBooleanShow only auctions you've bid on
priceNumberSet bid amount or starting price
time_lengthNumberAuction duration in hours (1–10)

/store view​

ParameterTypeWhat it does
store_numberNumberWhich store category to browse (1–5)

/store info / /store buy​

ParameterTypeWhat it does
item_idStringThe item ID to inspect or purchase

/inventory​

ParameterTypeWhat it does
item_name / indexString/NumberWhich inventory item to target (by name or index number)
effectStringRequired when using Effect Use Increase — the effect to extend

/plot​

ParameterTypeWhat it does
plot_numberNumberWhich plot to target (for info, upgrade, demolish)
globalBooleanLook at plots across all guilds

/guild​

ParameterTypeWhat it does
buildingStringWhich building to inspect (for /guild info)
amountNumberAmount to donate or convert
collectionStringTarget collection for guild lock

/tag​

ParameterTypeWhat it does
card_queryStringWhich card to tag
tag_textStringThe tag content to add or vote on

/transaction​

ParameterTypeWhat it does
transaction_idStringTarget a specific transaction
(filters)Various/transaction list supports optional filter parameters

Quick reminder​

If you're still getting comfortable with commands, the best approach is to start simple and let autocomplete help you. The advanced parameter syntax becomes much easier once you already know the basic command names and the kinds of cards you're trying to target. Feel free to bookmark this page and come back as you level up — there's always a new filter to try! 🚀
