# Card Management Commands 🛠️

:::info
This page is your full reference for managing, organizing, comparing, and evaluating your cards. All commands listed here are verified against the bot's command schema.
:::

## `/cards` — Browse your collection

The main command for viewing cards you own. Supports powerful queries to filter, sort, and search.

| Parameter | Type | What it does |
| --- | --- | --- |
| `card_query` | String (optional) | Filters, sorts, and searches your cards (see [Query Library](../getting-started/advanced/querylibrary) for the full syntax) |
| `global` | Boolean | If `true`, search the **global card pool** instead of your inventory |

### What you can do with `/cards`

- Browse all cards you own
- Filter by name, collection, star level, promo status, favorite state, and more
- Sort by evaluation value, name, date obtained, rating, XP level, and more
- Use `global:true` to search every card in the game
- Combine filters like `/cards card_query:-3 -twice >eval`

:::tip
The `card_query` parameter is incredibly powerful — check the **[Optional Command Parameter Library](../getting-started/advanced/querylibrary)** for the full syntax reference!
:::

## `/summon` — Show off a card

Display a single card from the global pool in all its glory. Great for showing others what a card looks like!

| Parameter | Required | What it does |
| --- | --- | --- |
| `card_query` | ✅ Yes | Name, ID, or partial match to find the card |

## `/info` — Check card details

Shows detailed information about any card, including its evaluation value, global statistics, and metadata.

| Parameter | Required | What it does |
| --- | --- | --- |
| `card_query` | ✅ Yes | The card to inspect |

### What `/info` shows you

| Info | Description |
| --- | --- |
| 💰 **Price** | Card's market evaluation value in ❄️ |
| 📊 **Average Rating** | Community rating (if rated by enough users) |
| 🌍 **Global Owners** | How many players own this card |
| 📋 **Demand** | How many players have this card on their wishlist |
| 🏷️ **Tags** | Top community tags applied to the card |
| 🎨 **Metadata** | Source, booru ID, and other reference info |
| 🆔 **Card ID** | Unique identifier |
| 🔢 **Times Auctioned** | How often this card has appeared in auctions |

## Comparison and checking commands

| Command | Required params | What it does |
| --- | --- | --- |
| `/has` | `user_id` + `card_query` | Check whether another player owns a specific card |
| `/diff from` | `user_id` | Compare your cards against another user's collection — shows cards you have that they don't |
| `/diff for` | `user_id` | Compare another user's cards against yours — shows cards they have that you don't |
| `/profile` | Optional `user_id` | View a profile-style overview for a player (includes level, cards owned, achievements) |
| `/stats` | None | Show your current player statistics |

## Wishlist commands 📋

Track cards you want to acquire. When a card on your wishlist is listed for auction, you'll get notified!

| Command | Required params | What it does |
| --- | --- | --- |
| `/wish one` | `card_query` | Add one card to your wishlist |
| `/wish many` | `card_query`, optional `count` | Add multiple cards to your wishlist at once |
| `/wish list` | None | View your current wishlist |
| `/wish remove one` | `card_query` | Remove one card from your wishlist |
| `/wish remove many` | `card_query`, optional `count` | Remove multiple wishlist entries |

## Favorites commands ⭐

Mark cards as favorites to protect them from accidental actions and keep them easy to find.

| Command | Required params | What it does |
| --- | --- | --- |
| `/fav one` | `card_query` | Mark one card as a favorite |
| `/fav many` | `card_query`, optional `count` | Mark multiple cards as favorites |
| `/fav remove one` | `card_query` | Remove favorite from one card |
| `/fav remove many` | `card_query`, optional `count` | Remove favorites from multiple cards |

:::tip
Favoriting a card protects it from accidental selling, liquefying, or use in forges/ascends. Always favorite your legendaries and valuable rares!
:::

## Evaluation and rating commands

| Command | Required params | What it does |
| --- | --- | --- |
| `/eval one` | `card_query` | Evaluate **one** card's market worth |
| `/eval many` | `card_query`, optional `count` | Evaluate **multiple** cards at once |
| `/eval many global` | `card_query`, optional `count` | Evaluate cards from the **global pool** |
| `/rate one` | `card_query` | Rate one card (1–10 scale) |
| `/rate many` | `card_query`, optional `count` | Rate multiple cards |
| `/rate remove one` | `card_query` | Remove your rating from one card |
| `/rate remove many` | `card_query`, optional `count` | Remove your ratings from multiple cards |

:::tip
Use `/eval` before selling or liquefying to know what a card is worth. Higher evaluated cards are generally more valuable in trades!
:::

## Mark commands 🏷️

Add emoji markers to your cards for quick visual identification in your collection.

| Command | Required params | What it does |
| --- | --- | --- |
| `/mark one` | `card_query` | Add an emoji marker to one card |
| `/mark many` | `card_query`, optional `count` | Add markers to multiple cards |

## Lock commands 🔒

Lock cards to protect them from accidental use in forges, combines, or ascends. Locked cards are also hidden from other players when they use `/has` or `/diff`.

| Command | Required params | What it does |
| --- | --- | --- |
| `/lock one` | `card_query` | Lock one card in your inventory |
| `/lock many` | `card_query`, optional `count` | Lock multiple cards |
| `/lock remove one` | `card_query` | Unlock one card |
| `/lock remove many` | `card_query`, optional `count` | Unlock multiple cards |

:::tip
Locking cards prevents other players from seeing them with `/has` or `/diff`. Use this if you want to keep certain cards hidden from comparison! 🕵️
:::

## A simple starter workflow

If you're new, here's a tidy little flow:

1. 📖 **Browse** — Use `/cards` to see what you own
2. 🃏 **Claim** — Use `/claim cards` to add new cards
3. 🔍 **Inspect** — Use `/info` to check a card's value and stats
4. 📋 **Track** — Use `/wish` to save cards you want later
5. ⭐ **Favorite** — Use `/fav` on cards you love
6. 💰 **Evaluate** — Use `/eval` before selling or converting
7. 🔒 **Protect** — Use `/lock` to safeguard your most valuable cards
