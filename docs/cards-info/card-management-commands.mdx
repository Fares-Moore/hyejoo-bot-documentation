## `/summon` — View a card

Summon and display a single card from your collection in all its glory. Great for showing off your rarest pulls or inspecting a card up close!

| Aspect | Details |
| --- | --- |
| Required param | `card_query` — name, group, or collection |
| Permissions | Any user |
| What you see | Full card art, name, star level, collection info, and any marks/ratings |

### Tips 💡

- Use `/summon` to show off a card to friends or in trade chats.
- Combine with `/info` to get the full picture before making a deal.

---

## `/info` — Card details

Get the complete dossier on any card: pricing data, how many players own it, how many have it on their wishlist, what tags are attached, and more.

| Aspect | Details |
| --- | --- |
| Required param | `card_query` — name, group, or collection |
| Permissions | Any user |
| Shows | Owner count, demand (wishlist count), tags, pricing info, and raw card data |

### What `/info` tells you 📊

| Data point | What it means |
| --- | --- |
| **Owner count** | How many unique players own at least one copy |
| **Demand / Wishlist count** | How many players have this card on their wishlist — higher demand usually means higher trade value |
| **Tags** | Community-applied tags (see the [Tag system](/tag) for details) |
| **Pricing** | The card's base evaluation, useful before selling or trading |

### Tips 💡

- Always check `/info` before buying, selling, or trading a card — knowledge is power!
- High demand + low owner count = a card worth holding onto (or listing on the auction house).

## Comparison commands

Compare your collection against others or check specific ownership.

### `/has` — Check card ownership

See whether another player owns a specific card. Quick and to the point!

| Aspect | Details |
| --- | --- |
| Required params | `target_user_id` + `card_query` |
| Permissions | Any user |

### `/diff from` / `/diff for` — Collection comparison

Compare your entire card collection against another player's to see who has what the other is missing.

| Command | Direction |
| --- | --- |
| `/diff from` | Shows cards **you** have that the **other player** is missing |
| `/diff for` | Shows cards the **other player** has that **you** are missing |

| Aspect | Details |
| --- | --- |
| Required param | `target_user_id` |
| Permissions | Any user |

:::tip
Use `/diff from` to find trade bait — cards you can offer to another player! Use `/diff for` to see what you're missing from their collection.
:::

### `/profile` — Player overview

View a profile-style overview for any player (or yourself if you omit the target).

| Aspect | Details |
| --- | --- |
| Required param | `target_user_id` (optional — omit for your own profile) |
| Permissions | Any user |
| Shows | Collection stats, clout count, achievements, and more |

### `/stats` — Your statistics

Show your personal user statistics at a glance.

| Aspect | Details |
| --- | --- |
| Required params | None |
| Permissions | Any user |

## `/wish` — Track cards you want

Your personal wishlist helps you keep track of cards you're hunting. When a card on your wishlist gets listed on the auction house, the bot will **DM you a notification** — no special effect needed!

### Subcommands

| Command | What it does |
| --- | --- |
| `/wish one` | Add one card to your wishlist 📋 |
| `/wish many` | Add multiple cards to your wishlist (optional `count` parameter) |
| `/wish remove one` | Remove one wishlist entry |
| `/wish remove many` | Remove multiple wishlist entries (optional `count` parameter) |

| Aspect | Details |
| --- | --- |
| Required param | `card_query` |
| Optional param | `count` (for `/wish many` and `/wish remove many`) |
| Permissions | Any user |

### Wishlist auction notifications 🔔

When a card on your wishlist is listed on the Auction House, the bot automatically notifies you — no passive effect required! This used to require the **Festival of Wishes 🎐** effect, but it's now a free feature for everyone.

### Tips 💡

- Build your wishlist early — it helps you track what to claim and makes auction sniping easier.
- Use `/wish many` to bulk-add cards from a collection you're trying to complete.

## `/fav` — Mark your favourites

Favouriting a card protects it from accidental selling, liquefying, or use in forges. Your favourites are also displayed prominently on your profile.

### Subcommands

| Command | What it does |
| --- | --- |
| `/fav one` | Mark one card as a favourite ⭐ |
| `/fav many` | Mark multiple cards as favourites (optional `count`) |
| `/fav remove one` | Remove favourite from one card |
| `/fav remove many` | Remove favourites from multiple cards (optional `count`) |

| Aspect | Details |
| --- | --- |
| Required param | `card_query` |
| Optional param | `count` (for `/fav many` and `/fav remove many`) |
| Permissions | Any user |

### Protection rules 🛡️

| Action | Protected? |
| --- | --- |
| Selling | ✅ Protected — cannot sell your last favourited copy |
| Liquefying | ✅ Protected — cannot liquefy your last favourited copy |
| Forging | ✅ Protected — cannot forge your last favourited copy |
| Collection reset | ✅ Protected — favourited cards won't be consumed if you only have one copy |

:::tip
Favourite your legendaries and rares first! This is the simplest way to prevent costly accidents.
:::

## `/eval` — Check card value

Evaluate a card's monetary worth in flakes ❄️. Essential before selling, liquefying, or trading.

### Subcommands

| Command | What it does |
| --- | --- |
| `/eval one` | Evaluate a single card |
| `/eval many` | Evaluate multiple cards at once (optional `count`) |
| `/eval many global` | Evaluate cards from the global pool (optional `count`) |

| Aspect | Details |
| --- | --- |
| Required param | `card_query` |
| Optional param | `count` (for `/eval many`) |
| Permissions | Any user |

### How evaluation works 📈

The evaluation is calculated based on the card's star level, collection type, and other factors. Higher-star cards and rarer collections generally evaluate higher.

### Tips 💡

- Always `/eval` before selling to the bot — you only get **40%** of the evaluation when selling directly.
- Use `/eval many global` to check values of cards you don't even own yet.
- Evaluation is the baseline for auction pricing (50%–400% of eval).

Rate cards in your collection on a personal scale. Your ratings are private to you and help you remember which cards you value most.

### Subcommands

| Command | What it does |
| --- | --- |
| `/rate one` | Rate one card |
| `/rate many` | Rate multiple cards (optional `count`) |
| `/rate remove one` | Remove a rating from one card |
| `/rate remove many` | Remove ratings from multiple cards (optional `count`) |

| Aspect | Details |
| --- | --- |
| Required param | `card_query` |
| Optional param | `count` (for `/rate many` and `/rate remove many`) |
| Permissions | Any user |

### Tips 💡

- Use ratings to mark trade priority — for example, rate cards you'd be willing to trade higher or lower.
- Combine with `/cards` to see your rated cards and sort by rating.

## `/mark` — Emoji markers

:::note
This command feature is only available to our Kofi Subscribers!
:::


Add a single emoji to a card as a visual marker. Marked cards show the emoji in your `/cards` list and on your profile, making your favourites stand out at a glance.

| Aspect | Details |
| --- | --- |
| Required param | `card_query` + an **emoji** |
| Permissions | **Ko-Fi subscribers only** (AmuPlus role required) |

### Subcommands

| Command | What it does |
| --- | --- |
| `/mark one` | Add an emoji mark to one card, or remove it if no emoji is provided |
| `/mark many` | Add/remove emoji marks from multiple cards at once |

### Rules 📏

| Rule | Details |
| --- | --- |
| **One emoji only** | You can only set a single emoji per card |
| **Emoji-only** | Text characters are not allowed — must be a valid emoji |
| **Ko-Fi required** | Only AmuPlus (Ko-Fi subscriber) users can use this feature |
| **Removing a mark** | Run `/mark one` without an emoji to clear the mark |

### Tips 💡

- Use distinct emojis to create your own visual system — 🔴 for trade, 💎 for keep, etc.
- You can also just use this to mark your bias' representative emojis for all of their cards in your collection! Many players do this just for aesthetics!
- If you apply multiple emojis by mistake, the bot will clear them automatically and ask you to try again.

## `/lock` — Inventory protection

Locking a card hides it from other players when they use `/has` or `/diff` on you. It also provides an extra layer of protection against accidents.

### Subcommands

| Command | What it does |
| --- | --- |
| `/lock one` | Lock one card 🔒 |
| `/lock many` | Lock multiple cards (optional `count`) |
| `/lock remove one` | Unlock one card |
| `/lock remove many` | Unlock multiple cards (optional `count`) |

| Aspect | Details |
| --- | --- |
| Required param | `card_query` |
| Optional param | `count` (for `/lock many` and `/lock remove many`) |
| Permissions | Any user |

### What locking does 🛡️

| Protection | Details |
| --- | --- |
| Hides from `/has` | Other players can't see your locked cards when checking ownership |
| Hides from `/diff` | Locked cards won't show up in collection comparisons |
| Selling | Locked cards are excluded by default — add `locked:true` to include them |

:::tip
Lock your most valuable or private cards so other players can't snoop on them! Combine with favourites for double protection.
:::

---

## Comparison at a glance — fav vs lock

| Feature | `/fav` ⭐ | `/lock` 🔒 |
| --- | --- | --- |
| Prevents accidental sell/liquefy/forge | ✅ Yes | ❌ No (but excluded by default from sell) |
| Hides from `/has` / `/diff` | ❌ No | ✅ Yes |
| Visible on profile | ✅ Yes | ❌ No |
| Protects from collection reset | ✅ Yes | ❌ No |
