# Hero System 🦸

:::note
You'll need to select a hero if you want to use **any** effects, so read through and pay attention!
:::

Your hero is your in-game mascot — an idol that represents you! And they're not just for show — they're the key to equipping **passive effects** that power up your gameplay. Let's meet your new bestie! ✨

## What's a hero? 🤔

Think of your hero as your **avatar**! Pick your favourite idol from a provided library , and they'll hang out with you through your Hyejoo adventures. Each hero has:

- A **name** and **ID**
- A **level** (earned through guild activity)
- **Followers** — how many other players have chosen the same hero
- A cool **picture/gif** made by the content team
- **Effect slots** — where you equip passive effects for awesome buffs

:::tip
Your hero shows up on `/hero slots` — that's where you equip passive effects. Pick someone you enjoy seeing, you'll be pals for a while! 💜
:::

## Getting your first hero 🎯

New to the game? You won't have a hero yet — here's how to get one!

### 1. Browse available heroes 👀

Use `/hero list` to see all the heroes you can pick from:

| Command | What it does |
| --- | --- |
| `/hero list` | Shows all available heroes, sorted by popularity |
| `/hero list hero:name` | Search for a specific hero by name |

Heroes are sorted by level, so the most popular ones show up first!

### 2. Pick your hero! 🎯

Found someone you like? Use `/hero get` to make 'em yours:

| Command | Required params | What it does |
| --- | --- | --- |
| `/hero get` | `hero` — Hero name or ID | Set a hero as your current hero |

**What happens when you pick a hero:**

- You'll get a confirmation prompt (don't worry, no surprises!)
- The hero's follower count goes up by 1
- Your old hero loses a follower (sorry, old pal!)
- A **7-day cooldown** starts before you can switch again

:::warning
You can only change your hero **once every 7 days**, so choose someone you like! The bot will tell you how much time is left if you try to switch too soon. ⏰
:::

### 3. Show 'em off! 🎉

Use `/hero show` to see your hero in all their glory:

| Command | What it does |
| --- | --- |
| `/hero show` | View your hero, level, followers, and equipped effects |
| `/hero info` | Get detailed info on any hero (submitter info, guild, etc.) |

Your hero display shows:
- Name and picture/gif
- Level and follower count
- All your **effect slots** — shows what's equipped or "Empty" if nothing's there

## Effect slots 🎯

Effect slots are where you equip **passive effect cards** for ongoing buffs. Think of 'em as gear slots for your hero! 🎒

### Starting slots

You begin with **2 passive effect slots** by default. When you first try to equip an effect, any missing slots are automatically created for you.

### Viewing your slots 👀

Use `/hero slots` (or `/effect list passives`) to check what you've got equipped:

| What you'll see | Details |
| --- | --- |
| Slot number | Slot 1, Slot 2, etc. |
| Equipped effect | Name + how much time is left on the buff |
| Cooldown | When you can swap effects in this slot |
| Duration | Time limit shown next to the slot if applicable |

### Slot capacity 📊

Your hero can hold multiple passives at once:

| Source | Max slots | Notes |
| --- | --- | --- |
| Default | **2** | Everyone starts here! |
| **Effect Slot Upgrade** | +1 per purchase | Buy from the bonus store for **50,000 🍋** |
| Level limit | 1 per 100 levels | Need to be level 100, 200, 300, etc. |
| Upgrade duration | **210 days** | Each upgrade lasts 210 days before expiring |

:::tip
Hit level 100? Grab your first **Effect Slot Upgrade** for 50,000 🍋 and get a 3rd slot for 210 days! Level 200 = 4th slot, and so on! 📈
:::

## Equipping effects ⚡

Ready to power up? Here's what you need:
1. A **passive effect card** (crafted from a recipe — see [Effect Cards](./effects-list))
2. An **empty slot** to put it in

### `/hero equip` — How it works

| Parameter | Required | What it does |
| --- | --- | --- |
| `slot` | ✅ Yes | Which slot number (1, 2, 3, etc.) |
| `effect` | ✅ Yes | The effect ID or name to equip |

**Step by step:**

1. 🏭 Craft a passive effect card (buy the recipe from the store, then use it from inventory)
2. ⌨️ Run `/hero equip slot:1 effect:tohrugift` (or whatever effect you want!)
3. ✨ Boom! The effect starts working immediately!
4. If the slot already has an effect, you'll get a prompt asking if you want to replace it

### Slot cooldown ⏳

Once you equip something, that slot goes on a **24-hour cooldown** before you can swap again. So choose your loadout wisely!

| Action | Cooldown |
| --- | --- |
| Equipping to a slot | 24 hours before you can swap |

### What happens when you equip

- The passive gets an **expiry date** (or keeps its existing one from crafting)
- The buff starts working right away
- The slot enters a **24-hour cooldown**

:::tip
Use `/hero slots` to see which slots are on cooldown — the timer's right there! ⏱️
:::

## Hero commands reference 📋

| Command | Required params | Permissions | Cooldown | What it does |
| --- | --- | --- | --- | --- |
| `/hero show` | *(none)* | Any user | None | View your hero and their equipped effect slots |
| `/hero get` | `hero` — Hero name/ID | Any user | 7 days | Set or change your hero |
| `/hero list` | Optional `hero` filter | Any user | None | Browse available heroes |
| `/hero info` | `hero` — Hero name/ID | Any user | None | View details about a specific hero |
| `/hero equip` | `slot` + `effect` | Any user | None* | Equip a passive effect to a hero slot |
| `/hero slots` | *(none)* | Any user | None | View your passive effect slots and equipped effects |
| `/hero submit` **(Not working currently)** | `*****` | Any user (level 25+) | 20 days | Submit a new character as a hero |
| `/effect list actives` | *(none)* | Any user | None | Show your usable active effect cards |
| `/effect list passives` | *(none)* | Any user | None | Show your passive effect cards (same as `/hero slots`) |
| `/effect info` | `effect` — Effect ID | Any user | None | Get details about a specific effect |
| `/effect use` | `effect` — Effect ID | Any user | Varies | Use an active effect card |

*\* Slot has a 24-hour cooldown after equipping before you can swap effects.*
