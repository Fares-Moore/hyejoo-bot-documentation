# Guild Plots & Buildings 🏘️

:::note
Guilds were originally built for a multi-server bot setup, but right now Hyejoo is only playable on the main Hyejoo Support Discord Server. Some guild mechanics might not feel as relevant right now!
:::
:::tip
But don't sleep on plots! You need **lemons 🍋** to buy items like **Effect Use Increase** (20,000 🍋 each), so it's totally worth getting into the plot system anyway! 💰
:::

Plots are your **passive lemon income** system! Buy a plot in a guild, build stuff on it, and earn 🍋 whenever other players do stuff in that server. It's like having a little business! 🏪

## Getting started with plots 🌱

You need to be at least **level 20** to start. (Check your level with `/profile`!) Each plot costs lemons, and the price goes up the more plots you own.

### Plot commands 🎮

| Command | What it does |
| --- | --- |
| `/plot list` | See your plots in the current guild |
| `/plot list global` | See all your plots across all guilds |
| `/plot buy` | Buy a new plot in the current guild |
| `/plot info` | Check details, stored lemons, and stats for a plot |
| `/plot info global` | View plot info across all guilds |
| `/plot upgrade` | Upgrade a building to the next level |
| `/plot collect` | Collect all stored lemons from your plots |
| `/plot demolish` | Tear down a plot + building, get 75% of invested lemons back |

### Plot limits 📏

- **Per guild**: Your guild level decides how many plots you can have. Roughly `ceil(guild_level / 8) + 1` plots per guild.
- **Global**: About `floor((player_level - 20) / 10) + 1` plots total across all guilds (minimum 1).
- **Minimum**: You need to be **level 20** before buying your first plot.

### Plot costs 💸

The cost doubles with each plot you own! Here's how it scales:

`25 × 2^(number of plots you already own)`

| Plots owned | Next plot cost 🍋 |
| --- | --- |
| 0 | 25 |
| 1 | 50 |
| 2 | 100 |
| 3 | 200 |
| 4 | 400 |
| 5 | 800 |
| 6 | 1,600 |
| 7 | 3,200 |
| 8 | 6,400 |
| 9 | 12,800 |
| 10 | 25,600 |

### Lemon cap 🍋

You can only hold so many lemons at once. Your cap is:
- **100,000 🍋** if your next plot costs less than 100,000 🍋
- Equal to your next plot cost if it's 100,000 🍋 or more

If collecting would go over your cap, the bot will warn you — you can still collect, but you'll lose the extra! ⚠️

## Buildings (Blueprints) 🏗️

Buildings go on your plots using **blueprints** bought from the store with 🍋. Each building needs a certain player level and has multiple upgrade levels!

### Important building rules 📏

:::tip
Build in the order the shop shows you, and max out all your plots in the server for the best 🍋 income! Most players can earn **16k–20k 🍋 every 24 hours** with maxed buildings on all plots. 💰
:::

- You **must build a Castle first** before anything else in a guild.
- You **can't have two of the same building** in the same guild.
- Buildings earn lemons from **other players' actions** in the guild, not your own.
- Buildings have **maintenance costs** paid from the guild's balance.

## Storage capacity

Each building has a maximum lemon storage before it stops earning more. The base storage caps are:

| Building Level | Base Storage |
| --- | --- |
| 1 | 300 🍋 |
| 2 | 600 🍋 |
| 3 | 1,200 🍋 |
| 4 | 1,800 🍋 |
| 5 | 3,600 🍋 |
| 6 | 7,200 🍋 |

Your Castle level increases this storage by a percentage. If your guild also has a **Lemonade Stand**, storage is boosted further by 10% per stand level.

## Collecting lemons 🍋

Use `/plot collect` to gather all stored lemons from your plots in a guild. You can collect once per hour.

- If collecting would exceed your lemon cap, the bot will warn you.
- You can choose to continue and forfeit the excess, or cancel.
- Collected lemons go directly into your balance.

## Demolishing plots

If you want to free up a plot slot, use `/plot demolish`:

- **Empty plots** are deleted with no refund.
- **Plots with buildings** give you back **75% of the total lemons** you invested (blueprint price + all upgrade costs).
- If you have multiple buildings and one of them is a **Castle**, you cannot demolish the Castle while other buildings exist in the guild.
- Demolished plots free up a slot so you can build something else.

## Quick tips

- **Castle first, always** 🏰 — You can't build anything else without a Castle on your plot. Make this your first purchase.
- **Choose your guild wisely** — Plots only earn from actions in the guild they're placed in. Active guilds with lots of players will earn you more lemons!
- **Collect regularly** — Buildings have storage caps, so if you don't collect, you'll miss out on potential earnings once they hit the cap.
- **Consider the Lemonade Stand** — If you're in a guild with active builders, a Lemonade Stand boosts everyone's storage, meaning less frequent collecting needed.
- **Level matters** — Many buildings and upgrades are locked behind player levels. Keep playing to unlock higher-tier options!
