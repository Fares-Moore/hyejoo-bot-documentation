# Events and Activities 🎉

Hyejoo Bot keeps things fresh with a *rotating lineup* of events and activities! From seasonal promo drops to limited-time challenges and community giveaways, there's always something exciting happening. This section covers everything you need to know about the bot's event system — so you never miss out on exclusive goodies! 🎁

## What's in this section 🗺️

| Page | What you'll find |
| --- | --- |
| 🎄 **[Seasonal Events](./seasonal-events)** | Holiday and seasonal promo card collections — Halloween, Christmas, Valentine's, and more! |
| ⏰ **[Limited-Time Activities](./limited-activities)** | Special one-off events like 1★ promo drops, anniversary celebrations, and Ko-Fi monthly rewards |
| 🌐 **[Community Events](./community-events)** | Games, giveaways, and other community-driven fun organized by server admins |

## How events work 🎡

- **Promo Collections 🎴** — Many events add special **promo collections** (marked with `promo: true`) that you can claim from using the boost parameter during the event period
- **Boost Drops 🎁** — During active boosts, every **30th claim** guarantees a special promo card drop. Talk about a loyalty reward!
- **Event Currency 💎** — Some events introduce a temporary currency you earn by claiming promo cards, which can be used to grab even more event cards
- **Limited Recipes 👩‍🍳** — Special event-exclusive effect recipes (like **Hyejoo Anniversary**) become available in the store only during the event
- **Expiration ⏳** — Promo collections have an `expires` date. After that, the cards can no longer be claimed. Better grab 'em while you can!

## Quick tips 💡

- 🔍 **Check active promos** — Use `/claim cards boost:promo` during active events to get special promo cards alongside your regular claims
- 🎯 **30 claims = boost drop** — During an active boost event, your 30th claim of the day guarantees a boost card drop. Plan your claims!
- 📈 **Event currency adds up** — Each promo claim earns you event currency. The more you claim, the more you can spend on extra event cards
- ⏰ **Don't miss expiration dates** — Keep an eye on event end dates. Once a promo collection expires, those cards are gone (until the next event comes around!)

## Key commands for events 🎮

| Command | What it does |
| --- | --- |
| `/claim cards boost:` | Claim event cards using an active boost ID during a promo period |
| `/claim cards promo:true` | Spend event currency on promo cards |
| `/balance` | Check your event currency balance |
| `/daily` | Reset claim cost and get fresh currency for more event pulls |
