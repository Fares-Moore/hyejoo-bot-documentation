# Events and Activities 🎉

Hyejoo Bot keeps things fresh with a *rotating lineup* of events and activities! From seasonal promo drops to limited-time challenges and community giveaways, there's always something fun happening. Never miss out on exclusive goodies! 🎁

## How events work 🎡

- **Promo Collections 🎴** — Events add special promo collections you can claim with a boost parameter during the event
- **Boost Drops 🎁** — During active boosts, every **30th claim** guarantees a special promo card drop. Freebies! 🎉
- **Event Currency 💎** — Some events have a temporary currency you earn by claiming promo cards, which you can spend on even more cards!
- **Limited Recipes 👩‍🍳** — Event-exclusive effect recipes (like **Hyejoo Anniversary**) show up in the store only during events
- **Expiration ⏳** — Promo collections have an expiration date. Grab 'em while they're hot!

## Quick tips 💡

- 🔍 **Check for active promos** — Use `/claim cards boost:` during events for bonus promo cards
- 🎯 **30 claims = guaranteed drop** — Your 30th claim during a boost event is a guaranteed special card. Plan accordingly!
- 📈 **Stack that event currency** — More claims = more event currency = more promo cards!
- ⏰ **Don't wait too long** — Event cards disappear when the event ends. Grab 'em while you can!

## Key commands for events 🎮

| Command | What it does |
| --- | --- |
| `/claim cards boost:` | Claim event cards with an active boost ID during a promo |
| `/claim cards promo:true` | Spend event currency on promo cards |
| `/balance` | Check your event currency balance |
| `/daily` | Reset claim cost and keep earning more!
