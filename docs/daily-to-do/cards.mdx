# Cards 🃏 — Browse Your Collection

## `/cards`

See every card you own, all in one place! Filter, search, and sort to find exactly what you're looking for. Each card shows its **name**, how many **copies** you've got, any **emoji mark** you've set, and more handy details. 🖼️

### Command parameters

| Parameter | Required | What it does |
| --- | --- | --- |
| `card_query` | ❌ Optional | Filter by card name, group, or collection |
| `global` | ❌ Optional | Set to `true` to browse the **entire card pool** instead of just what you own |

### What you'll see 👀

| Info | What it means |
| --- | --- |
| **Card name** | The name of your card |
| **Copies** | How many you've got (trading dupes, anyone?) |
| **Emoji mark** | Any custom emoji you've set (Ko-Fi perk!) |
| **Star rating** | From 1★ to 5★ — the rarer the better! |
| **Rating** | Your rating + what the community thinks |
| **Lock status** | 🔒 means it's protected from accidents |

### Handy filtering tips 🔍

- **Search by name** — `/cards card_query:tohru` finds all Tohru cards
- **Search by group** — `/cards card_query:twice` shows your Twice collection
- **Search by collection** — Use collection IDs to filter specific sets
- **Global search** — `/cards global:true card_query:rare` searches the full card pool

Check out the [Optional Command Parameter Library](https://fares-moore.github.io/hyejoo-bot-documentation/docs/getting-started/advanced/getting-started-advanced-querylibrary#common-parameter-types) for more advanced filtering options! 🔎
